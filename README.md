# Колективне звернення до АТ «ДТЕК Київські електромережі»

Цей репозиторій — майданчик для підготовки та підписання **колективного звернення**
спільноти користувачів сервісу «Світлобот» до **ДТЕК** щодо своєчасного інформування
про відключення, машиночитаних даних, єдиної термінології та якості напруги.

## 📨 Текст звернення

Офіційна зафіксована версія: **[zvernennya.md](./zvernennya.md)**.

Робоча чернетка для спільного редагування — Word-документ `zvernennya.docx`
у OneDrive (див. [CONTRIBUTING.md](./CONTRIBUTING.md), розділ «Як ми працюємо
над текстом»).

## Запропонувати правки

Будь-хто з обліковим записом GitHub може запропонувати зміни через **Pull Request**
з власної копії (fork), без доступу на запис до цього репозиторію.
Мейнтейнер перевіряє та приймає правки перед їх включенням до офіційної версії.
Інструкція для редагування прямо в браузері: [CONTRIBUTING.md](./CONTRIBUTING.md).

## ✍️ Як підписатися

Додайте свій підпис у [SIGNATURES.md](./SIGNATURES.md) через Pull Request —
деталі в [CONTRIBUTING.md](./CONTRIBUTING.md).

## 📎 Матеріали

Скриншоти та інші матеріали, що ілюструють проблеми (таймаути, розсинхронізація
статусів), зберігаються в папці [assets/](./assets).

## 🎯 Мета

- Отримати від ДТЕК відповідь по суті кожного пункту звернення у строки,
  визначені Законом України «Про звернення громадян».
- Домогтися своєчасного офіційного інформування про екстрені відключення
  та машиночитаного джерела даних для волонтерських сервісів.
- Зібрати підписи учасників спільноти під зверненням.
