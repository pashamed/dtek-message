# Колективне звернення до команди СвітлоБот / ДТЕК

Цей репозиторій — майданчик для підготовки та підписання **колективного звернення**
локальної спільноти **Svitlobot** до команди СвітлоБот щодо правильної та безпечної
інтеграції з їхніми сервісами.

## 📨 Текст звернення

> Привіт, команда СвітлоБот! 🇺🇦
>
> Пишемо вам колективно від спільноти мешканців **Svitlobot** _(≈N учасників, лінк на чат)_.
>
> Ми хочемо налаштувати **некомерційні сповіщення про статус електропостачання за
> нашими адресами** для внутрішнього чату спільноти — і зробити це правильно,
> не створюючи зайвого навантаження на вашу інфраструктуру.
>
> Підкажіть, будь ласка:
>
> 1. Чи є офіційна документація API або умови використання для кастомних інтеграцій?
> 2. Які rate limits ви вважаєте прийнятними для таких запитів?
> 3. Чи є webhook/push-механізм, щоб ми могли отримувати оновлення без постійного
>    опитування серверів?
>
> Зі свого боку гарантуємо: кешування відповідей, частоту запитів не вище
> рекомендованої, exponential backoff при помилках і повну прозорість — наш код
> буде відкритий у цьому репозиторії.
>
> Контакт для звʼязку: _(e-mail / Telegram)_. Будемо вдячні за будь-яку доку,
> лінки чи поради! 🙌

- Зібрати підписи учасників спільноти під зверненням.
